# 局部接触形态的定位与量化

在两个WT生物学重复上，对344条已知结构和726个全基因组扫描位置分别分析50、100、200 bp三种尺度。16个独立未注释候选固定来自`results/unannotated_shape_clusters/candidate_new_structures.csv`。所有位置执行相同的局部定位，包括作为对照的未注释背景。

## 方法

以WT rep1背景窗口估计逐基因组距离的接触期望，计算O/E后消除窗口平均幅度。在有效观测像素上，比较sigma=1与sigma=8的高斯平滑结果，提取局部正向富集响应。沿矩阵对角线枚举8、16、24、32、48、64、96 bins的方形区域，步长4 bins，按正响应总量除以有效像素数量的0.75次方评分。定位不使用已知类别或已知区间边界，两个重复独立选择区域；距离不足200 bp及低覆盖行排除，局部有效上三角比例至少50%。

每个局部区域测量20项几何描述量，包括富集质心、离对角线距离、主方向、长宽比、沿轴与垂轴离散度、行列峰值集中度、正反对角峰值集中度、熵、连通分量、边缘质量和边界梯度。另生成32×32对齐图像。保留使用相同描述量的整窗对照，以检验定位是否改善表征。

在原有空间五折上，仅使用rep1拟合分类器、标准化和图像PCA，分别评估rep1与rep2。模拟未知形态时，从训练参考、标准化和PCA拟合中完全排除一个已知类型，计算其到剩余已知类型的最近距离，分别与其他已知类型、未注释背景比较。背景O/E期望从原有全局背景拟合，未按折重新拟合；因此验证属于回顾性、存在全局预处理信息共享的探索性比较，不能称为完全独立的外部评价。

## 已知结构验证

| 表征 | rep1 Macro-F1 | rep2 Macro-F1 |
| --- | ---: | ---: |
| 整窗几何对照 | 0.562 | 0.574 |
| 局部几何 | 0.473 | 0.525 |
| 局部对齐图像 | 0.426 | 0.428 |

局部化未获得总体分类优势。50 bp下OPCID估计区间与原注释的中位IoU为0.779（rep1）、0.755（rep2），CHID约0.499；CHIN仅约0.399和0.435。100/200 bp下，CHIN容易被邻近更强信号吸引，其中200 bp的中位注释IoU为0。重复定位一致不能替代与注释位置的正确对应。

隐藏CHIN时，局部几何对其他已知类型的AUC为0.721/0.707，超过整窗的0.616/0.635；但隐藏CHID时约0.521/0.523，隐藏OPCID时约0.441/0.454。因此该表征没有证明能够普遍识别未知类型。所有类别与方法，包括不利结果，保留于`held_type_novelty_summary.csv`。

## 候选形态证据

16条候选均增加估计起止位置和局部长度（800、1600、2400、3200、6400 bp），保留原始扫描窗口坐标。估计值来自有限尺度网格，表示接触富集区域的算法足迹，不是已验证的生物结构边界。

- 13/16条在两个重复中的100 bp定位区间IoU至少0.5；C0055、C0198、C0225不满足。即使相同物理位置的O/E相关较高，算法选中的最强局部区域也可能改变。
- 每条候选有形态上最近的已知参考、三项最大标准化几何差异、两个重复中的差异方向，以及三尺度并排热图。位置未注释与形态不同分别判断。
- 以接触密度、局部有效像素和富集质心离对角线距离匹配背景，排除候选25.6 kb以内位置。所有背景运行相同多尺度定位搜索。匹配集合从1至185个不等，样本不足单独标记。对照涵盖局部定位搜索，但未完整复制原始AE候选排名和全基因组候选选择，背景尾比例仅是描述性诊断，不是发现p值或FDR。
- C0152的局部定位分数在164个匹配背景中的加一尾比例约0.036，且其局部O/E重复相关约0.973，值得保留。但该候选最接近OPCID_21，两个重复均未超出已知参考距离范围，不能据此称为新形态。
- C0075估计长度2.4 kb，同位置局部O/E重复相关约0.902；与最近参考OPCID_18相比，200 bp长宽比更大、最大连通分量占比更低、边界梯度更弱，三个差异方向在重复中一致。但其匹配背景尾比例约0.52，且未通过已知形态距离筛查。

局部几何重新分组得到C0144/C0152两成员组，但rep2组内最大距离略超过预设背景距离半径，且成员未同时达到背景罕见性和已知形态区分规则。符合全部规则的疑似新形态簇仍为0。局部特征与解释功能已建立；新类别的生物学证据尚未建立。

候选资格规则要求：边界IoU≥0.5、有效像素上的对齐形态相关及同位置O/E相关均≥0.5、至少20个匹配背景且定位尾比例≤0.05、两个重复均超过已知参考距离95%界限、三项最大几何差异中至少两项方向一致。簇至少2个独立成员，且rep2组内距离不超过从背景几何距离5%分位数确定的半径。阈值用于探索性证据组织，不保证控制误报率。

## 结果入口

- `localized_candidates.csv`：16条候选的扫描坐标、估计边界、几何区别、最近已知形态、重复验证与证据状态。
- `per_window_geometry.csv`：344+726个位置 × 3种尺度 × 2个重复，共6420行的全部测量。
- `localization_stability.csv`、`known_localization_summary.csv`：跨重复边界、有效像素形态相关与已知边界参照。
- `known_classification_predictions.csv`、`known_classification_summary.csv`：三种表征的空间折外分类对照。
- `held_type_novelty_scores.csv`、`held_type_novelty_summary.csv`：逐位置与类别留出新颖性验证。
- `localized_clusters.csv`、`candidate_cluster_centers.npz`：局部几何簇与中心。
- `heatmaps/C*.png`：16份三尺度双重复定位热图；`heatmaps/C*_known_comparison.png`：16份三尺度双重复最近已知形态对照。全图色标0至2，均排除不足200 bp接触及未充分支持像素。
- `geometry_validation.png`：分类、定位正确性和候选边界复现的合并视图。
- `measurements.npz`、`measurement_signature.json`、`distance_expectation.json`、`protocol.json`、`summary.json`：可复用测量、特征代码签名、期望曲线和固定方案。
