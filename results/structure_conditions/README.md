# 已知结构的条件差异定位

入口：`.venv/bin/python scripts/structure_conditions.py`，随后运行 `.venv/bin/python scripts/structure_condition_shape.py`。原始矩阵路径与来源哈希见 `protocol.json`。使用 WT（37C）、HNS_mut、FIS_mut，每种条件两个生物学重复；比较全部344条已知结构。

每个结构提取自身及左右各一个结构长度的上下文，统一按200 bp边界对齐。在100 bp矩阵上计算中心结构内的接触密度，排除相距不足200 bp的像素。对每一个基因组距离，用左右侧翼内同距离接触的均值作为背景，并按中心像素数量加权。中心与背景的比值称为局部富集。该指标对整体乘法缩放不变；每百万文库接触归一化后的绝对信号另行保存，避免混淆整体变化与局部变化。

两个条件的重复不视为配对样本。变化幅度为两个突变重复与两个WT重复的平均log2富集差，同时检查全部四个跨条件差值。筛选规则见 `protocol.json`：变化绝对值至少0.5，超过条件内重复差异的95%经验分位数，所有跨条件差值方向一致且绝对值至少0.25；200 bp聚合与100 bp行边际校正后方向不变且幅度至少0.25。行边际校正可能去除部分真实生物信号，只用作敏感性检查。

`structure_changes.csv` 保留全部688个比较，包括未通过筛选的结果；`repeat_consistent_changes.csv` 保留通过规则且中心至少80%行观测到接触的结构。该支持度不是独立测定的可比对性。`shape_and_support.csv` 在逐样本侧翼距离背景校正后，将中心O/E向量按平均幅度归一化，比较重复内与条件间形态距离。形态分离规则是四个跨条件RMSE均超过最大条件内RMSE的1.25倍，且两个条件的重复相关系数均至少0.5。

热图展示每种条件局部富集变化绝对值最大的四个筛选结构；每组四幅图使用相同色标，显示文库归一化密度的log1p值。青线表示原始注释边界。热图排名与形态分离判据相互独立。

两个生物学重复不足以对单条结构作有力的显著性检验，不提供像素伪重复的p值或FDR。所有阈值为探索性描述规则。已知结构及其上下文可能重叠，688个比较不相互独立。侧翼可能包含其他已知或未知结构，背景变化也会影响局部富集；结果不能单独证明结构类别消失或某因子的直接机制。数据与已知坐标此前用于其他分析，本比较属于回顾性探索。

## 结果

所有344条注释共形成688个条件比较。按三种侧翼宽度、两种背景、四种跨重复组合及经验重复噪声筛选后，保留10个条件比较，涉及9条不同结构和8个最大侧翼重叠组。HNS_mut中有7条局部富集增强、1条减弱；FIS_mut中有2条减弱。8/10个比较同时呈现独立计算的重复一致形态分离。

| 结构 | 条件 | 局部富集变化 | 相对WT的富集倍数 |
| --- | --- | ---: | ---: |
| OPCID_10 | HNS_mut | −1.134 log2 | 0.46 |
| OPCID_10 | FIS_mut | −1.088 log2 | 0.47 |
| OPCID_15 | FIS_mut | −1.670 log2 | 0.31 |
| CHIN_229 | HNS_mut | +1.098 log2 | 2.14 |

四个重点位置在0.5、1、2倍结构长度的侧翼下，以及排除其他已知结构注释的侧翼背景下，变化方向均保持一致。它们也都超过六种敏感性设定各自的经验噪声99百分位与观测最大重复差异。图像标出原始结构边界：OPCID_10和OPCID_15的中心信号减弱在两个重复中均可见；CHIN_229在HNS_mut重复中均显示注释区内交叉信号增强。热图见 [稳健性核查目录](robustness/README.md)。

按最大侧翼上下文重叠组统计，1倍清洁背景下WT组内重复差异的95百分位为0.174 log2、99百分位为0.235，最大值0.255。全部六种敏感性设定中，最大组内重复差异为0.308 log2；10个候选效应均超过它。该经验噪声参考用于筛除小幅或依赖特定背景的变化，不是置换检验、FDR或家族错误率控制。

所有结构绝对接触信号变化的中位数为HNS_mut −0.624 log2、FIS_mut −0.530 log2；局部富集变化中位数分别为+0.073和+0.057 log2。全局接触量下降不能等同于所有已知结构减弱。8个HNS_mut和2个FIS_mut比较所涉及的9个结构仍是回顾性观察；两个生物学重复不足以证明单条结构统计显著、确定新结构类别或识别直接调控机制。

## 44C热应激扩展

WT与44C双重复矩阵在匹配参考与分辨率下对全部344条结构进行同规则筛查，保留16项稳健比较，其中13项的目标区接触密度变化与局部富集变化同向且达到0.25 log2阈值，另3项主要由侧翼变化解释。NCBI/SRA read-count 对照强烈支持系列级WT与44C Cooler来自同平台的t2（DNBSEQ-T7）重复；文件级GSM对应仍未显式标注，故属于高置信推断。详细核对见[44C分析说明](44C/README.md)与[证据合并表](evidence_synthesis/README.md)。

## 平台与空间依赖核查

对10项突变候选及16项44C候选统一分解目标区和侧翼密度，并核对扩展上下文重叠。26项条件比较涉及25条不同结构注释和21个上下文组；同一OPCID_10在HNS_mut与FIS_mut中重复出现。44C中13项为目标区主导变化，HNS_mut中仅OPCID_10达到目标区主导，另有多个CHIN候选主要受侧翼背景下降影响。HNS_mut与FIS_mut的样本分别采用DNBSEQ-G400与DNBSEQ-G50，而WT矩阵高度可能来自DNBSEQ-T7，因此突变条件结论仍受平台混杂限制。合并分解、位置关系、平台审计和可复现脚本见[evidence_synthesis](evidence_synthesis/README.md)。
