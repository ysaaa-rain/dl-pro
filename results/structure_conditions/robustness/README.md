# 条件差异的稳健性核查

核查覆盖WT（37C）、HNS_mut、FIS_mut各两个生物学重复及344条已知结构。输入矩阵来源和SHA-256见上级目录的 `protocol.json` 与 `integrity.json`。此分析沿用原始结构坐标，不改变注释边界。

## 背景与重复噪声

对每条结构分别使用结构长度的0.5、1、2倍作为两侧侧翼宽度。目标与背景只比较相同基因组距离的接触；为了让三种背景宽度使用相同的目标距离范围，全部固定在200 bp至结构长度的一半。每种宽度再比较两种背景：包含全部侧翼像素，或剔除与其他已知注释区间重叠的像素。两种条件的重复视为不配对，逐结构检查四种突变重复与WT重复组合。

WT两个重复在1倍侧翼、排除邻近已知结构的背景下，按最大的2倍侧翼上下文划组后，各组内重复差值绝对值的中位数为0.065 log2、95百分位为0.174、99百分位为0.235，最大为0.255。将WT、HNS_mut、FIS_mut三个条件共243个“组内最大重复差值”合并形成经验噪声参考，1倍清洁背景下95百分位为0.134、99百分位为0.215、观测最大值为0.255 log2。每一种宽度和背景均单独计算阈值，见 `empirical_noise_summary.csv`。

这个经验参考用于判断候选是否远大于本数据的重复波动，不是置换检验、校正后的p值或FDR控制。只有两个重复，无法对单条结构给出有力的生物学显著性推断。四种跨条件组合共享样本，也不能作为四次独立实验。

## 保留的变化
