# 未注释窗口的形态聚类与重复证据

输入为全基因组异常扫描保留的37个未注释、原始O/E重复相关达标窗口。重新计算公共有效像素上的O/E相关：34个通过相关≥0.5且有效上三角像素≥50%的条件，21个完整25.6 kb上下文及200 bp缓冲区不交已知注释，按25.6 kb中心间距去除空间冗余后保留16个窗口。这些来自原始异常扫描，与多检测器共识路线得到的4个窗口不是同一队列。

采用100/200 bp两尺度、16×16池化的幅度归一化O/E形态向量，经仅拟合WT rep1背景窗口的12维PCA投影后，用DBSCAN聚类。背景两两距离的5%、10%、20%分位数作为三个距离尺度，分别检查2、3个独立成员的门槛。主设置为10%距离分位数、至少2个成员。其余设置用于敏感性分析。

主设置得到一个2成员簇（C0075、C0279），在rep2中保持同簇。20%尺度还得到一个3成员簇，但该簇不能在rep2中保持一致。共四项簇与设置组合均未通过形态新颖性和匹配背景检验。因此，允许2—3成员确实能形成候选形态组，但当前证据仍不支持新的结构类别。

形态新颖性要求每个成员的两份重复均超过留出已知结构到训练已知结构最近距离的95%分位数；这是参考形态距离诊断，不是生物学新颖性的充要条件。200组匹配接触密度、内部空间隔离的背景集合用于检查偶然小簇，并取全部六个设置的最大簇大小为比较量。背景诊断尾比例均为1，表明仅形成2—3成员簇不足以区分背景。该背景参考可能含有未注释结构，且未严格匹配所有技术变量，不能作为正式发现p值。

## 输出与复现

- `candidate_audit.csv`：全部37个窗口的坐标、评分、重复相关、有效像素、已知结构邻近、空间独立性及排除原因。
- `candidate_new_structures.csv`：16个独立可复现未注释窗口；包含主设置簇归属，`cluster=-1`表示DBSCAN未归簇。它是候选清单，不是确认新类别清单。
- `cluster_evidence.csv`：各设置的簇、成员、代表窗口、跨重复簇一致性、已知形态距离和背景诊断。
- `cluster_centers.npz`：每个设置中每个簇的12维中心；`shape_representation.npz`保存两个重复的窗口向量、PCA参数和已知参考向量。
- `heatmaps/`：全部37个窗口的双重复热图，固定色标0至2、统一幅度归一化log(1+O/E)；屏蔽距离不足200 bp的对角带。坐标和长度表示扫描窗口，不表示已确定的生物结构边界。
- `shape_embedding.png`：已知结构、未注释背景与独立候选的二维投影。
- `matched_background_control.npz`、`protocol.json`、`summary.json`：背景结果、参数和计数。

运行：`.venv/bin/python scripts/cluster_unannotated_shapes.py`。

候选与背景在同一基因组中，且部分背景窗口参与过表征拟合；这些结果为回顾性探索，不能描述为独立测试。已知结构与背景的空间隔离表征评价见`results/discovery/representation_check.json`（balanced accuracy 0.723、AUC 0.789）；全基因组窗口评分与已知召回保留在`results/discovery/all_windows.csv`及`known_recall.csv`。全基因组高召回排序、新颖性检验和形态簇证据仍需联合改进，当前不能宣称完整发现目标已经实现。

逐候选的多尺度局部定位、具体几何差异与已知类型留出验证，见[局部接触形态分析](../local_contact_morphology/README.md)。该分析保留估计边界和不利对照，未建立新的形态类别。
