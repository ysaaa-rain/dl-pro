# 全量候选的结构证据分析

入口清单为`candidate_inventory.csv`。原始全基因组检测保留的294条候选全部进入分析，不以簇成员数或已知成员比例决定是否保留。沿用已冻结的六个AE/PCA形态簇，不通过调整聚类参数追求特定的新形态数量。检测器的评分、空间窗口及既有召回结果均未重新优化。

## 候选与簇

| 证据类别 | 数量 | 含义 |
| --- | ---: | --- |
| 已知结构关联候选 | 84 | 基础质量通过，窗口或200 bp缓冲范围关联已知注释 |
| 未注释且接近已知形态的候选 | 28 | 基础质量通过、位置未注释，整窗几何处于已知参考距离范围 |
| 形态异常待验证候选 | 6 | 基础质量通过、位置未注释，两重复均超过整窗已知参考距离范围；仅为异常标记 |
| 重复或信号质量不足 | 176 | 共同有效像素或其上的重复相关不足，仍保留测量和热图 |
| **全部候选** | **294** | **逐条有坐标、评分、簇、证据和PNG** |

基础质量规则为：两个WT重复的公共有效上三角像素至少50%，其O/E相关至少0.5；行有效性要求至少80%的原生10 bp碱基有观测接触。基础质量通过的118条中，34条在窗口及200 bp缓冲范围内没有已知注释。25.6 kb完整上下文是否含已知注释另行记录，不作为进入分析的硬排除。

6个簇均为混合簇，所有成员保留。簇规模分别为8、87、41、65、59、34；簇内基础质量通过的未注释成员分别为1、2、6、7、8、10。`cluster_inventory.csv`给出成员、代表窗口、质量及已知/未注释组成，`cluster_centers.csv`保留原始12维PCA中心。`mixed_cluster_reference_subgroups.csv`按最近已知形态参考组织簇内子组，只表示参考相似性，不代表新生物学类别。

## 个体证据

每条候选分别记录：

- 实际扫描区间、中心、物理长度及环形跨原点分段；独立的局部估计区间与长度。
- 与已知注释的精确重叠、200 bp缓冲关联、完整上下文关联、最近已知区间边缘距离。
- 公共支持像素上的重复O/E相关、有效比例、两重复局部边界IoU及跨尺度一致性。
- 最近已知形态参考、三项最大几何差异，以及两个重复中对应差异的方向。
- 密度、局部支持度和离对角线位置匹配的背景数量与局部定位尾比例。
- 质量等级、空间代表标记和具体的新颖性证据限制。空间代表标记不删除任何行。

形态参考使用三尺度整窗几何特征；局部几何分类能力较弱，故只作为定位和解释的补充。最近参考类型不是经过充分校准的类别预测，不能把“接近CHIN参考”直接解释成“识别出新的CHIN”。

全部294条均有四面板热图：候选WT rep1/rep2、几何最近已知结构WT rep1/rep2。统一采用100 bp分辨率、幅度归一化log(1+O/E)、0至2色标，排除不足200 bp的接触及支持不足行；青框为各重复独立选择的局部富集足迹。热图横轴为局部bin，真实坐标保存在CSV，避免环形跨原点窗口产生错误连续坐标。

## 六个整窗几何异常候选

| 候选 | WT支持像素O/E相关 | 匹配背景数 | 局部定位尾比例 | 主要证据限制 |
| --- | ---: | ---: | ---: | --- |
| C0011 | 0.785 | 3 | 0.250 | 背景样本不足，跨尺度定位不一致 |
| C0059 | 0.896 | 22 | 0.217 | 较大上下文含已知注释，背景区分和跨尺度一致性不足 |
| C0144 | 0.971 | 13 | 0.071 | 背景样本不足，跨尺度一致性不足 |
| C0186 | 0.689 | 1 | 0.500 | 背景样本不足，跨尺度定位不一致 |
| C0216 | 0.631 | 181 | 0.549 | 较大上下文含已知注释，局部信号不比匹配背景突出 |
| C0230 | 0.807 | 178 | 0.156 | 重复与跨尺度定位稳定，但局部信号缺乏背景罕见性 |

这些候选不能因为距离超阈值就称为新形态。综合重复、几何差异方向、背景和跨尺度证据后，本分析未建立疑似新形态。`tentative_new_shape`是个体综合证据标记，不受簇成员数或簇中已知成员影响；即使未来单个候选满足，也只能表述为待独立验证的个体新形态线索。

该标记要求：基础质量通过、候选窗口无已知缓冲关联、两个重复均超出已知几何参考范围、三项主要几何差异至少两项同向、至少20个匹配背景且定位尾比例≤0.05、重复局部边界IoU≥0.5、各尺度物理区间最小IoU≥0.5。它用于组织探索性证据，不是误报率控制。候选未通过时，具体缺口写入`novelty_evidence_assessment`，候选本身仍完整输出。

背景定位对照执行相同多尺度局部搜索，但未复制原始AE筛选的全部选择过程；尾比例不是p值或FDR。既有坐标和重复曾被反复分析，所有结果属于回顾性探索。位于独立空间位置、跨重复相似和无注释，并不足以独立证明新的生物结构类别。

## 数据入口与复现

- `candidate_inventory.csv`：任务二当前全量候选入口，294行。
- `quality_supported_candidates.csv`：基础质量通过的118行，供聚焦阅读。
- `unannotated_candidates.csv`：基础质量通过且扫描区间及缓冲范围未注释的34行。
- `cluster_inventory.csv`、`cluster_centers.csv`、`mixed_cluster_reference_subgroups.csv`：混合簇组成及子组。
- `heatmaps/`：294份逐候选双重复与已知形态对照图。
- `candidate_evidence_map.png`、`protocol.json`、`summary.json`、`integrity.json`：证据分布、方案、计数与完整性核验。
