# 未注释局部结构及形态分析

## 判定对象与依据

本分析识别的是未被现有清单注释、在两个WT生物学重复中可复现、具有整窗形态差异的局部接触结构。采用“操作性新结构发现”描述满足下列规则的候选位置；这里的“新”限定为相对于本实验344条已知注释及其几何参考的新增发现，不表示首次生物学发现或已确立的新结构类型。

操作性规则同时要求：

1. 公共有效上三角像素比例至少0.50，且其上的两重复O/E相关至少0.50；行有效性采用至少80%原生10 bp碱基有观测支持。
2. 12.8 kb候选窗口及200 bp缓冲不与已知注释重叠。
3. 两重复整窗几何到已知训练参考的距离均超过已知校准样本距离的95%分位数5.69476。
4. 相对于最近已知几何参考，三项最大几何差异中至少两项在两个重复中同向。

这是一组可执行的探索性定义，参考范围仅覆盖现有标注和所用几何表征。95%距离阈值不是新类型概率，也未控制全基因组筛选误报率。整体重复相关不能单独证明某一局部图案的新颖性。局部背景、跨尺度位置及大上下文关联用于解释证据强弱，不把缺乏统计功效误写为结构不存在。

## 六条形态异常发现

六条均满足上述操作性定义，全部保留。现有证据未直接证伪其中任何一条局部结构的存在；同时，没有一条已完成对已知形态变体、复合信号及背景解释的排除。结论为六处操作性未注释形态异常结构发现，不将六处位置解释为六种新类型，也不将原始混合簇解释为新的纯形态簇。

C0144的整窗相关0.971支持信号稳定，主轴指标在100及200 bp下相对参考同向偏离；局部跨尺度最小IoU为0.333，说明不同尺度边界变化，不能将3200 bp估计视为固定结构长度。其13个匹配背景的尾比例0.071属于低功效的描述性证据，既不是显著新颖性的证明，也不能证明它只是背景。

C0230具有更好的局部位置一致性；但“位置稳定”和“形态新颖”是不同结论。其十字条带与已知CHIN参考相似，178个匹配背景尾比例0.156。该位置作为可复现未注释结构发现成立，作为独立新形态类别尚未成立。

## 另一类结果：未注释已知样结构

另保留28条基础质量通过、无已知缓冲重叠、整窗形态未同时超出已知参考距离范围的候选。它们用于描述现有注释之外的已知样形态分布，不视为已确认的CHIN、OPCID或CHID新成员。最近参考类型仅是相似性线索。六条异常候选与这28条候选互不重叠，共34条未注释候选记录；记录数不是独立生物结构数量，部分候选可能是同一邻域的滑动窗口，空间代表标记随表保留。
