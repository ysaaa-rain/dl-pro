# 第六轮定向优化：固定协议

日期2026-10-17。此前全基因组扫描覆盖全部染色体，且空间测试位置已多次观察；本轮所有结果统一属于历史空间探索性评价，不称独立最终测试。配置为`configs/targeted_review_v1.json`，原始数据、旧模型及第五轮产物均保留。

## 任务二

旧自编码器确实完成五折背景训练，但缺支持像素损失、两重复严格转移和留类验证。本轮沿用相同Autoencoder网络，不扩大网络。固定30轮、两种子，以重复1合法训练背景拟合200/100bp距离期望（自编码器使用100bp通道）、幅度不变变换及支持像素995分位数缩放。仅有效上三角像素参与逐窗损失；对称重建用于残差，避免对称接触重复计数。验证背景重建误差选轮数。

完全复用第五轮纠正后的15组留类/空间背景、参考、验证索引。隐藏类别上下文只用于保守排除，不用于训练标签、特征选择或阈值选择；排除所有已注释上下文会错删未知结构背景，未注释也不保证无结构。参考过少和嵌套标签限制仍保留。

核心对照为支持形态基线、背景AE残差、AE与方向形态联合、500次相同预算随机基线。AE残差对密度/零值/支持/远区比例的线性Ridge校准只拟合训练背景；验证背景定义经验秩和阈值，不称全基因组p值。方向特征沿用既有实现，不增加尺度。联合权重固定各半；仅当允许类别与背景的验证AUROC比AE、形态二者均高至少0.02且两信号验证相关绝对值<0.9时启用，否则回退AE。每折写选择锁后评价留出标签。两个固定种子的经验残差秩取平均，单种子诊断保留。潜变量到允许参考的距离单独作新颖性诊断，不生成额外候选。

64/128为原726格点等效预算，按空间合格测试格点比例分配（实际预算单列）；不得与原全基因组64/128绝对数量混用。最小间隔12.8kb、完整25.6kb已知上下文排除、200bp缓冲、跨重复相关0.5、共同上三角比例0.5、独立成员间隔25.6kb、至少5成员不变。完整候选统一做WT质检、固定6簇及HDBSCAN，并计算可用条件的描述性形态/强度。候选的双重复相关不等于新生物类型证明。

## 任务五

第五轮的共享双重复形态及跨重复目标训练全部复用。本轮只补两种匹配的原生唯一接触条件NLL：重复1自身40→10bp监督、两个重复各自自身监督。相同ConditionalDistributionSR、训练231位置/21块、两种子、320步、batch4、学习率和数据增广。独立的空间/重复随机流保证两臂抽到相同空间批次与反向增广；模型初值相同。双重复不增加独立空间样本数。

低输入严格为原生16图像像素均值。距离先验/归一化/OE背景直接复用第五轮训练拟合值；同一空间区域两个重复的划分相同。唯一上三角NLL不把粗对角块的重复像素当独立读段。目标空块不提供分配信息，仍计入完整评价；同重复下源零等价于目标整个块零，不存在源正目标全零的跨重复冲突。模型输出为期望图像计数，不是实际整数读段。

两臂用同一个双重复验证NLL选择轮数。统一验证包含第五轮全部固定模型与约束/无约束插值、均匀和训练距离先验；先满足对旧正式结构重训臂的同/跨PSNR不降超0.02dB、原生SSIM不降超0.002，再按跨重复100bp OE SSIM选择，种子指标平均不选最好种子。写全部权重哈希和验证选择锁后一次性评价全部固定模型，报告同/跨和双方向、空间组区间、计数约束及已知结构子集指标。原任务一分类器需完整12.8/25.6kb上下文，不能把10.24kb patch强行补零后冒充分类恢复；本轮在patch内实际完整的已知结构上评价形态和位置。

噪声诊断覆盖每个训练/验证空间窗、全部距离层和全部预定计数层；不只保留高计数块。跨重复相关和误差分解仅作经验诊断，不是不可突破的理论上限。若共享同重复模型仍不提供可重复形态收益，停止本轮网络搜索，不追加损失或继续搜索权重。

文献动机：[Learning Not to Reconstruct Anomalies](https://arxiv.org/abs/2110.09742)指出背景重建好不自动保证异常分离；[Noise2Noise](https://proceedings.mlr.press/v80/lehtinen18a.html)讨论噪声目标下的恢复学习，生物重复并不自动满足其假设。本轮均以实际对照检验，不借论文宣称保证有效。
