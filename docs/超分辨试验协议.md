# 任务五：首轮真实数据试验协议

目的：用真实 WT 37℃重复数据打通 40 bp → 10 bp 的图像超分辨训练、基线比较与空间留出评价。此轮是小规模试验，不代表选做任务已完成。

## 数据与划分

参考 NC_000913.3，原生分箱 10 bp。只用完整的 100 kb 区块，每个区块在 25% 和 75% 位置选取一个 1280 bp 窗口。46 个区块、92 个位置，两个重复共 184 个样本。末端不足 100 kb 的区域及跨环状起点区域不纳入本轮。

种子 42 将区块打乱后按 32/6/8 划分训练/验证/测试；同一位置的两个重复使用同一划分。样本数为 128/24/32。不同集合没有窗口重叠，但这仍是空间留出，不是整条染色体或生物学重复独立留出。

## 退化和模型

原始 128×128 计数图按 4×4 块平均得到 32×32 输入，先平均再做 log1p；这是图像分辨率退化，不是测序深度下采样。对完整对称矩阵作图像池化，不能将对角块的和直接解释为不重复计数的物理接触数。

高低分辨率共同使用训练集 log1p 强度的 99.5% 分位数缩放，并截断到 [0,1]。该参数只在训练集估计。输入不做 ICE 平衡；跨重复深度差异尚未单独校正。

基线为双线性、双三次插值。CNN 为三层 3×3 卷积，隐藏通道 16，学习双线性插值后的残差，输出对称化。CPU 确定性训练，Adam，学习率 0.001，12 轮，按验证 MSE 选择检查点。测试集不参与选择。

## 评价与解释范围

在相同 [0,1] 变换强度上计算 PSNR（峰值 1）、SSIM（data_range=1）、MSE 和去主对角线 MSE；分别按重复报告均值，保留每个测试窗口的指标。PSNR 的零误差情况使用 1e-12 数值下限。

结果不能等同于生物结构恢复：1280 bp 窗口不覆盖多数完整标注结构，数据稀疏性可能导致平滑模型获得较好 MSE。后续需更大窗口、多随机种子、距离分层评价、跨重复泛化和已知结构形态/位置恢复验证。不得把重复之间相关的窗口当作独立生物学样本作显著性检验。

## 可复现运行

```bash
.venv/bin/python -m pip install -e '.[test,experiment]'
.venv/bin/python scripts/extract_annotations.py
.venv/bin/python -m dlpro.superresolution --output results/sr_pilot --epochs 12 --seed 42
```

已有小体积提取数据时，无需下载两份大矩阵即可复跑：

```bash
.venv/bin/python -m dlpro.superresolution --dataset results/sr_pilot --output results/sr_reproduction --epochs 12 --seed 42
```

源矩阵的精确文件大小和 SHA256 见 results/data_migration.json。提取数据包含原始窗口数值与完整坐标/划分表；完整来源恢复入口见根目录课程 PDF 和补充下载说明。

实现参考：[PyTorch 插值接口](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.interpolate.html)、[scikit-image 指标接口](https://scikit-image.org/docs/stable/api/skimage.metrics.html)。具体安装版本以依赖锁文件及运行 protocol.json 为准。
