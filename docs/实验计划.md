# 实验设计与验收计划

依据：根目录《基于深度学习的接触矩阵处理实践方案.pdf》，重点第 8–14 页。任务一、二、三均为必做，任务四至六至少选择一项。用户已确定选做任务五：接触矩阵超分辨重建。

## 数据接入门槛

- 主数据：37℃ WT 两个独立生物学重复；核实样本名、染色体长度、10 bp 分箱与计数类型。
- 结构注释：structures.csv，预期 344 条；也可能为 table4/5/6 原始表，需先核实列及坐标约定再转换。
- 多条件绘图：至少三个实验条件。不能把两个重复当成两个条件。
- 基因轨道：匹配 MG1655 参考版本的基因注释；以矩阵染色体信息核验，不凭名称猜测映射。
- 数据审计记录原文件体积、SHA256、来源、重复对应关系与共享许可。0-based 半开区间是内部协议，源表是否 1-based 必须核实。

## 方法选择与对照

### 任务一：有监督识别（40 分）

以结构中心提取多尺度局部窗口，先训练小型 CNN；与多数类、接触总量/长度特征和 PCA+线性分类器比较。小样本条件下先建立可解释基线，不直接堆叠大型视觉模型。输出准确率、macro-F1、每类召回、混淆矩阵数值和图、模型权重及显著性图。

训练/验证/测试按实际输入窗口的重叠连通组划分；同一位置的全部重复共用组。先审计组数及类别分布，禁止随机拆分近重复窗口。归一化参数只在训练集拟合，超参数只用验证集选择，保留测试集最终评估。显著性结合遮挡验证，检查模型是否主要依赖背景密度。不同窗口尺度使用共同的最大范围组，避免跨尺度泄漏。

### 任务二：候选发现（30 分）

以距离归一化矩阵为形状输入，用卷积自编码器学习背景并打分；原始接触量单列作为对照。候选发现与已知标签监督训练分开记录。报告全基因组有效窗口数、过滤原因、候选数与已知结构召回率，避免只展示高分图。

对形状表征降维和聚类；重复独立生成评分，rep1 用于发现、rep2 用于验证。复现性用排除主对角线的有效上三角 O/E 相关，零方差记为不可评估。阈值用验证背景校准；已知区间重叠、邻近关系与已知识别器结果分别列出。疑似新簇需满足成员数、已知结构排除和跨重复验证，但不能据此宣称发现新的生物学类别。环状距离与跨起点区域需显式处理，当前基础读取器不支持跨起点拼接。

### 任务三：多轨道可视化（10 分）

固定 10000 bp 区间覆盖全基因组，最后一个区间截断至染色体末端。四轨为至少三个条件的接触强度、平均信号、基因、已知结构。深度归一化、接触距离范围、重复合并方法和统一色标明确记录。

### 选做（20 分）

建议任务五：用合并 bins 构造低分辨率输入，以轻量残差 CNN 对比双线性/双三次插值，输出 PSNR/SSIM 及已知结构恢复图。分辨率降低与测序深度下采样分别实验，不混为同一种退化。已获用户选择确认。

## 交付

代码 ZIP、PPT 讲解视频、实验报告分别提交；报告先生成可编辑 DOCX，由用户审阅后自行转 PDF。报告包含设计思路、对照、指标、限制、图表、成员分工和贡献百分比。组号、姓名、学号及贡献待用户提供，不能自行编造。PPT 后续按 live PowerPoint 质量流程制作。课程示例中的 8 kb、8 成员、0.68 只作为参考，不得写成本实验结果。

## 实施顺序

1. 数据清单与格式审计 → 确认真实样本和坐标协议。
2. 正式预处理、重叠分组与划分审计 → 冻结测试集。
3. 基线与 CNN → 重复种子评估、显著性及遮挡对照。
4. 候选发现与独立重复验证 → 未注释候选清单及限制。
5. 多条件轨道与选做实验 → 汇总真实结果。
6. 报告、PPT、视频录制提纲、可复现代码包。
