# Micro-C辅助标注工具

启动：

```bash
.venv/bin/python scripts/annotation_server.py
```

浏览器打开 http://127.0.0.1:8765 。仅绑定本机；无需额外Web依赖。使用现有实验环境和已提交模型。输入NC_000913.3的0-based中心坐标，范围0–4,641,651；两轴均按基因组从左下递增。可用U004、U007或已知CHID示例。

工具展示WT两个重复的50/100/200bp三尺度模型输入、三类别概率、重复间概率、预测类别梯度敏感性及相邻已知标注。每尺度显示实际分箱起止坐标；跨环状起点会注明。已知与扫描中心可用已提交缓存；任意其他坐标需要恢复WT两份原始Cooler，首次读取前核验原件SHA256。

人工可接受建议类别或选择CHID/CHIN/OPCID/不确定/其他，并填写理由。保存会新增一条SQLite记录，默认路径data/annotations/human_reviews.sqlite3，不覆盖课程标签，也不自动加入训练。反复修正保留完整历史。记录包含坐标、UTC时间、原始概率、模型及归一化文件哈希、数据来源哈希、空间折、人工标签和备注。可导出CSV或含完整来源的JSON。未保存的备注不会持久化；新预测会清空备注。测试库单独放在.qa，界面测试记录不是生物学人工标注。

模型为固定三种子FineScaleClassifier集成，先分别对重复计算softmax，再对种子和重复取平均。归一化与模型同折。工具优先采用与当前完整25.6kb上下文重叠的已知结构所在测试折；若重叠跨越多个折，则提示含训练/验证重叠，只供探索。不存在已知训练输入重叠不等于外部独立验证。三分类是封闭类别建议，不能证明新结构类别，特别是原始注释存在嵌套时。

概率未经置信度校准；梯度是对归一化输入的预测类别logit敏感性，不是统计显著性、因果机制或独立生物证据。梯度幅度在两个重复和三尺度内共同归一化，显示0–1相对值。低梯度不说明区域不重要。图像使用模型归一化O/E与近对角线掩码，不应将暗区一律解释为测序缺失。
