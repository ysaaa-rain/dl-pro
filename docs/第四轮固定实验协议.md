# 第四轮固定实验协议

2026-10-16。在运行本轮指标前固定以下两个假设。测试位置来自已反复观察的同研究空间块；本轮仍是探索性回顾比较。

## 任务二：方向形态是否被原评分遗漏

原八维评分只提取各向同性的局部正对比，难以区分细长反对角线、条带和团块。新增平滑 O/E 图像 Hessian 的反对角线、主对角线、水平、垂直曲率与线状脊响应；尺度 sigma=1/2/4/8，100/200 bp 两视图。仍使用原 6.4 kb 格点，80% 原生支持行、有效中央区域、原每折背景期望与训练背景。只在训练背景拟合密度校准。报告新方向特征单独评分及与旧八维特征联合评分，固定正值均值和循环验证选择三种聚合的结果，不根据测试扩大参数。

固定64/128名额、12.8 kb间距，原56空间组五折，两重复分别打分，重复2不拟合或选配方。与原形态评分、预算匹配随机和原森林检测对照比较。已知结构中心召回只是检测代理；未注释簇仍按完整25.6 kb上下文排除、重复QC、至少5个独立成员审核。

## 任务五：直接学习计数分配，避免稀疏目标的均匀回退

上一轮重复2目标投影中，验证集35%的源非零块在目标为零，均匀回退引入了人为平滑目标。新增条件计数分配损失：在源与目标均非零的40 bp块内，以目标原始10 bp计数加权预测的16像素概率，零目标块不提供分配监督。近对角线(<200 bp)与远区分别按目标计数归一化后等权。该损失是对称接触像素的复合条件负对数似然，不宣称读段独立。

固定两个匹配训练臂：重复1目标、重复2目标；相同ContextCountSR、源重复1低分辨率输入、原64训练和12验证位置、种子42、960步、batch4、Adam及原余弦学习率。每80步以各自验证分配损失保存检查点。评价全部固定臂，不能按测试决定哪一臂为主方法。重复2目标臂是本轮主要假设，重复1目标臂用于分辨目标与损失的作用。

统一比较原32同重复测试窗口和16跨重复位置的PSNR/SSIM、100 bp掩码O/E SSIM、计数误差与8空间块配对区间；保留旧约束双三次、sparse_matched、dense_multiscale和第三轮跨重复模型。原测试目标不同的指标不混合。外部数据和人工核验仍是进一步确认的必要来源。

依据：Noise2Noise论文说明独立噪声目标可以用于恢复学习，但生物重复、log变换与块投影不自动满足其理想假设，本轮只检验具体计数目标的效果。论文：https://proceedings.mlr.press/v80/lehtinen18a.html 。

## 方向实验后的单项诊断追加

方向特征完成后发现已知结构森林的总体召回提高，但OPCID在64候选时从0.235降到0.103；CHIN占训练注释大多数。随后固定一个追加对照：架构、特征、训练样本与所有参数保持不变，只把阳性扫描窗口按最近训练注释的类型赋予逆频率权重，使三类阳性权重总和相同。候选类型仅作为训练权重来源，不进入推理特征。无权重搜索，不使用验证或测试选择此对照；并列报告总体和三类平均召回。此追加明确由已观察结果触发，仍属探索性诊断。
