# 第四轮实验结果与方法取舍

执行日期：2026-10-16 至 2026-10-17。对应固定方案见《第四轮固定实验协议.md》，第三轮失败对照见《任务二与任务五第三轮迭代.md》。所有测试位置均已被前序实验观察，本轮属于同研究、空间分组的回顾性探索。

## 任务二：方向表示提高已知检测，但仍未获得新簇

原评分的八个特征来自各向同性局部对比，新增四尺度、两视图的方向曲率和线状脊，共40个特征。沿用原726个格点、每折隔离的背景和期望，仅在训练背景拟合密度校准；重复2不拟合、不选配方。方向特征与旧特征联合后，各折循环验证均选择最大值聚合。预先固定的“方向正值均值”分支同时保留，其重复1的64候选召回反而降到0.2703，说明并非所有方向评分都改善。

| --- | ---: | ---: | ---: |

64候选时，方向森林相对原形态评分的总体召回差，在重复1为+0.1221，56空间组95%重采样区间[+0.0428,+0.1928]；重复2为+0.0872，区间[+0.0179,+0.1557]。这是本轮较明确的已知结构检测进展。联合形态法的差分别为+0.0349和+0.0552，但两区间均跨0，仍缺稳健收益证据。重复不构成独立标签集，累计模型搜索也不在这些区间中。

收益与类别取舍相伴。64候选重复1的CHID召回从0.5000升至0.7308，CHIN从0.2920升至0.4720，OPCID从0.2353降至0.1029；重复2的OPCID也从0.2500降至0.1324。类型权重追加对照部分恢复OPCID至0.2059 / 0.2206，同时损失其他类型，总体和三类平均召回均没有稳定提高。最近训练注释类型所分配的阳性扫描窗口，每折只有3至7个为CHID，说明粗窗口标签和嵌套注释会放大权重不稳定性。该对照未被选作新主方法。

64候选的重复间精确中心Jaccard：原形态0.8190、联合方向形态0.6720、方向森林0.7461。新的评分会改变候选组成，不能只以总体召回上升概括效果。监督森林定位为已知结构检测对照，其标签信息不能转写为无监督新结构发现。

## 任务五：条件计数损失取得小幅跨重复形态收益

两个匹配臂均使用原64个训练位置、12个验证位置、种子42、960步和相同ContextCountSR。40 bp源计数保持不变；条件损失直接用目标的原始10 bp计数监督块内16像素概率，不为零目标块生成均匀标签。近、远对角线分别按计数归一化后等权，验证检查点只按对应目标的条件损失选择。两个臂均在第960步取得最低验证损失。

主要假设“条件损失、重复2目标”相对dense_multiscale的跨重复原生100 bp掩码O/E SSIM增加0.003029，8空间块配对区间[+0.002218,+0.003923]；PSNR差+0.000295 dB，区间[-0.001356,+0.001560]，没有可靠PSNR增益。原生SSIM降低0.000851。同重复形态分数的两重复平均降低0.001107；重复1的配对差区间也位于0以下。把重复2目标投影到源40 bp总量后，100 bp形态指标降低0.000829，区间[-0.001361,-0.000336]，说明收益依赖具体评价目标。

相对同为64训练窗的sparse_matched，跨重复形态差为+0.001174，区间[+0.000746,+0.001609]，但PSNR降低0.006626 dB。两个本轮匹配臂之间，改用重复2目标仅额外提高0.000386形态SSIM，区间[+0.000247,+0.000574]；重复1目标的条件损失本身已达到0.34825。结果支持直接计数损失带来有限的形态取舍，不能把总体变化全部归因于跨重复监督。此前dense与sparse窗口数不同的对照不作为纯损失消融。

决定：保留条件计数模型为形态目标的实验分支，既有操作方案不切换。它没有同时改善原生PSNR、SSIM及同重复形态，更没有证明能恢复不可复现的10 bp细节。全部固定臂、验证曲线和负面指标均保留在`results/sr_conditional/`，没有根据测试重新选配方或继续搜索混合权重。

## 本轮诊断结论和后续边界

任务二的格点加密失败，而方向表示在已知检测中取得进展，说明排序表示比扫描格点更值得改进；类别混合、粗窗口标签及嵌套注释仍限制检测的均衡性。无监督形态分支的区间较宽，且4个合格候选不足以组成既定新簇，继续提升已知召回不能代替新结构证据。

任务五的主要限制来自高稀疏度和块内信息不足。第三轮已测得10 bp训练像素约88%为零，消除40 bp块总量后，两重复的块内细节相关很低。改用条件计数损失可调整形态与原生误差的取舍，收益幅度仍小。下一轮应优先引入更深覆盖或独立来源的匹配数据，以及对候选区域的人工核验；现有测试位置上的连续调参不足以建立外部泛化或新类别结论。本轮停止在固定实验臂的完整评价处。

## 复现与核验

新增`.gitattributes`固定CSV、JSON和源代码的LF字节，解决Windows自动CRLF检出造成的清单哈希不一致。原注释表、划分和模型不作内容变更。恢复的原始Cooler与大型`.npy`数组只在本地保留，下载脚本、哈希清单、模型和逐例指标可独立审阅。

环境安装：`python -m pip install -e ".[experiment,test]"`。分阶段运行`python scripts/run_task2_task5_iteration.py --stage sources`、`--stage prepare`、`--stage discovery`、`--stage superresolution`、`--stage review`；完整复算使用`--stage all`。默认只执行review。训练有每80步恢复状态；重新训练时应使用新的输出目录或保留旧结果后移动恢复状态，不能混用不同协议的恢复状态。所需原始小缓存、冻结划分和基线权重来自Git仓库。

23项测试全部通过，包括原五折冻结概率复现、新方向形态的幅度不变性，以及计数分配损失对无观测目标的零梯度检查。最终来源、逐例唯一性、空间隔离、直接Cooler读取和计数约束检查全部通过，记录在`results/iteration_review/audit.json`。预先固定的验证与测试探针中，40 bp块均值最大相对误差小于5.1e-7。汇总对照图与四个候选热图均已打开核验。
